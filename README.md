# 📊 Customer Churn Analysis – Power BI

This project analyzes **customer churn** using Microsoft Power BI.

### 🛠️ Tools

* Power BI
* Power Query
* DAX
* Data Visualization

### 📌 Dashboard Includes

* Total Customers
* Churned Customers
* Active Customers
* Churn Rate
* Churn Analysis by Customer Attributes

### 🎯 Objective

To identify **customer churn patterns** and generate insights that help improve customer retention.
